# 谱选区表示实验（selection representation experiment）

本文件由 `scripts/run_selection_experiment.py` 运行生成，全部数字来自当次运行的 `exports/selection_experiment/results.json`，不复算不得手改。

## 设置

- 同一逆变换原型：`spectralpaint.dsp.stft → 实数增益 → istft`（与编辑器引擎完全相同的 rfft/OLA 路径），两种表示只是**选区的存储形式**不同。
- 创建窗 W1：n_fft=2048, hop=512, hann（频箱 21.533 Hz，帧步 11.61 ms）；重开窗 W2：n_fft=4096, hop=1024, hann（频箱 10.767 Hz，帧步 23.22 ms）。
- 候选表示：
  - `curve`：连续选区存为曲线（f_lo(t)、f_hi(t) 折线，秒/Hz 物理单位），求值时再栅格化；
  - `mask_pixel`：带原始窗参数的系数掩码，按像素（频箱/帧序号）固化重开；
  - `mask_resample`：同一掩码按物理坐标线性重采样到新网格；
  - `mask_strict`：同一掩码，网格不符即拒绝重开。
- 显示网格（画布像素）在任何一条路径中都不参与存储或求值：坐标只有秒/Hz 或绑定显式窗参数的 STFT 单元。

## C. 撤销成本

- 每条选区持久化体积：curve **72 B** （控制点折线）vs 系数掩码 **1,426,800 B** （174 帧 × 1025 箱 × float64）。
- 每次重建的求值耗时（W1 网格，60 次均值）：curve 重栅格化 1.318 ms vs 掩码直接取用 0.030 ms。
- 两者的撤销语义相同：从列表删除选区后由原始谱整体重建（测试套件逐位验证），不存在反向增益误差累积；差异只在持久体积与每次重建的求值耗时。

## 结论：存储策略

1. **以连续边界（曲线，秒/Hz 物理单位）为选区的唯一真实存储。** 变窗后在当前网格上重新求值，掩码边界漂移不超过新网格的量化步长（见 A/B 表 curve 行），目标带与相邻带行为与 W1 参考一致。
2. **系数掩码只能作为派生缓存，且必须绑定生成它的窗参数。** 跨窗按像素固化重开会把切口平移到别的频带/时段：本实验中 940–1060 Hz 切口漂到 474–528 Hz，目标 1000 Hz 几乎未衰减而相邻 500 Hz 被误伤；瞬态编辑的 0.5–1.0 s 窗口漂到 0.98–2.02 s，误伤 click@1.15/1.575。因此跨窗重开只有两种可接受策略：拒绝（strict）或重采样（resample，边界仍带着旧网格量化误差，且体积大三个数量级）。
3. **精度**：曲线以 float64 存边界，精度不受任何网格限制；掩码的边界在创建时即被量化到旧窗频箱（W1 下 ±10.8 Hz / ±5.8 ms），任何重开策略都无法找回。
4. **撤销成本**：曲线每条选区几十字节、重建时重栅格化约零点几毫秒；掩码每条选区约 1.4 MB、重建时零求值但换窗即失效。编辑会话的撤销栈应存曲线（或等价的物理单位笔画），掩码只在导出/渲染管线末端按需生成。
5. **显示网格不是音频真实坐标**：本实验全部测量在物理坐标（秒/Hz）或绑定显式窗参数的 STFT 单元上进行；画布像素只负责显示，任何“按显示像素固化选区”的做法等价于 mask_pixel，变窗/缩放即错位。
